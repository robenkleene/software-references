# Spotlight

- To restart Spotlight, toggle `Finder > Preferences > Advanced > Show all filename extensions` (it's unclear why this restarts Spotlight, but it works to, e.g., fix Spotlight UI glitches)
- When Spotlight switches to a running application, it only brings the frontmost window forward
- `⌘↑` / `⌘↓`: Move up / down sections in Spotlight results
- `tag:foo`: Search for a tag
