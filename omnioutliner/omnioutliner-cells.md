# OmniOutliner Cells

## Rows

- `⌘-click` a row to select it (e.g., this avoids toggling a checkbox or a disclosure indicator, or starting to edit a row)

## Columns

- To apply a style to a whole column, select the column by clicking the header, then change the styles
- Inspector `Selection Style > Column Type` sets the type (e.g., `Date`, `Checkbox`, `Rich Text`, `Number`, `Duration`, `Pop-Up List`)
- You can't delete the default column (the one with the row handles). You also can't switch which column this is, or seemingly even cut and paste a column.
- You can't select or copy a single column in OmniOutliner (remember too that rows within columns can be nested)

### Sorting

- `Organize > Keep Sorted`
