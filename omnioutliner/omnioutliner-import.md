# OmniOutliner Import

- Oddly you cannot paste either CSV or TSV into OmniOutliner and have it support columns, instead you can save TSV *only* with `.txt` as the file extension, and OmniOutliner will open it respecting columns (oddly you can't drag the `.txt` file to the OmniOutliner icon, you have to use `File > Open...` (`⌘O`)
